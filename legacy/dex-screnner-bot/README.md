# DexScreener AI Sentinel 🤖

A specialized Discord bot that monitors the crypto markets (via DexScreener), performs AI-driven due diligence to filter out scams, and delivers high-quality intelligence logs.

## Features
- **Real-time Monitoring**: Watches for new pairs and trending tokens.
- **AI Analysis**: Uses LLMs to analyze token metadata and potential red flags.
- **Scam Filtering**: Automated checks for liquidity, volume, and suspicious patterns.
- **RAG-Ready**: Stores data in a structured format for future AI training/retrieval.

## Setup
1. Clone repo.
2. `npm install`
3. Copy `.env.example` to `.env` and fill in keys.
4. `npm run dev`
